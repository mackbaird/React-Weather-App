# 🌤️ React Weather App

A responsive and user-friendly weather application built with **React** as part of the **SheCodes** workshops. This app fetches real-time weather data for any city using the [OpenWeatherMap API](https://openweathermap.org/api), displaying current temperature (in both Celsius and Fahrenheit), weather conditions, humidity, and wind speed—complete with a matching weather icon.

---

## 🚀 Live Demo

🌐 [View the App on Netlify](https://baird-react-weather.netlify.app/)

---

## 🔍 Features

- 🌡️ Real-time temperature in **Celsius** and **Fahrenheit**
- 🌬️ Displays **humidity** and **wind speed**
- ⛅ Matching **weather icon** for current conditions
- 🔎 **City search** functionality
- 📱 Fully **responsive** layout for all devices

---

## 🛠️ Built With

- [React](https://reactjs.org/)
- [Axios](https://axios-http.com/)
- [OpenWeatherMap API](https://openweathermap.org/api)
